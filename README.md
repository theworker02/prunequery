# prunequery

Prune structured JSON query payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/prunequery/

## Install / run

```bash
git clone https://github.com/theworker02/prunequery.git
cd prunequery
node src/cli.js
node --test
```
